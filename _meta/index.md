## Literature / papers

- [[literature/papers/chen2026repo]] — Repo-To-Skill / DisCo (**operational knowledge as a third layer**, distinct from backbone and harness: the know-how that separates knowing a method from making it work, present in repos but too bulky to load. AREX-Skill Library = 5,000+ verified skills from 1,000 ML repos in 20 areas / 178 capability families. With **backbone, harness and execution budget held fixed**: MLE-bench **+134.3%**, PaperBench +34.4%, FrontierCS +9.2%, PassNet +14.0%. The direct counter-evidence to kassis2026scientific's honest null — `compression-as-generalization-test` now has a matched null and positive on the same question. 178 families are the retrieval index, i.e. the `mocs/` layer at scale. Caveats: "verified" at 5,000 units rests on an unreported oracle, and no artifact released. rel 5 / cred 4)
- [[literature/papers/goyal2026does]] — Memory portability across a model upgrade (**the assumption `agent-native-memory` rested on, measured for the first time, and the split runs through this repo's own note format.** Under a writer swap: KG-fixed +0.0004 ± 0.0020 (immune); model-compressed NOTES **+9.91 or −13.28 pp, asymmetric by direction**. A note here is both — **YAML frontmatter is KG-fixed, Markdown prose is NOTES** — so the frontmatter is the durable layer. Decisive second finding: **80% of the NOTES deficit is write-time construction loss**, store-only repair failed 90% recovery in all 48 cases vs 34/48 with raw history retained — an independent performance argument for the immutable `raw/` rule. Caveat: synthetic randomized answer codes are compression-hostile, so the magnitude is an upper bound. rel 5 / cred 3)
- [[literature/papers/brueckner2026kbench]] — K-Bench (real scientific agent requests, **no ground truth**: 1,602 runs, 9 frontier models, identical sandboxes, 3 *blinded* judges, 39,934 judgments. **No model clears the acceptability line under all three judges**; gpt-5.6-sol leads on pooled mean 8.04 but its CI spans the threshold and two of three judges rank claude-opus-5 first, so the authors report **ordering as the reproducible quantity and the top of the table as unresolved**. Scientific accuracy 6.22 vs communication 7.33 **in the same direction in every one of nine models**; leading failure tag is **overclaiming at 31.4%**. Same group as kassis2026scientific — the evaluation that paper admitted it lacked; treat as one programme, not two attestations. rel 5 / cred 3)
- [[literature/papers/yang2026truthinsightbench]] — TruthInsightBench (**reproduction vs discovery**: existing AI-scientist benchmarks build tasks around a hidden target study and reward recovering it; this withholds conclusions, expected values and analysis paths, leaving the agent to determine what claim the data support. 40 blind tasks from 40 peer-reviewed studies, 10 domains; fixed LLM judge over 6 dimensions as **29 artifact-grounded items**, deterministic aggregation, no per-instance human grading. Four coding agents plateau **58.4–60.3/100** with no reliable pairwise separation — strong on auditability and novelty, but **controls, robustness, falsifiability and cross-dataset generalization largely absent**. That list is directly usable as completion-contract evidence requirements. Authorship effectively anonymous; code released. rel 5 / cred 2)
- [[literature/papers/yoon2026arcticswarm]] — ArcticSwarm (**deliberate isolation as an epistemic device, and the inverse of paglieri2026case**: peer access to partial findings makes parallel agents converge early, so gated isolation lets selected searches keep their own prior while a bulletin board carries integration. BrowseComp-Plus **82.6%** (Qwen 3.5-27B) vs 78.8% without gated isolation vs 74.5% without structured review either; live-web BrowseComp 73.6% with GPT-5 vs provider 54.9%. Forces a third position on `shared-substrate-contagion`: the shared channel carries reuse, defects **and premature consensus** — and the axis is *when* (isolate while gathering, share while integrating), not topology. Caveat: motivated by verifier-free research, evaluated on a verified benchmark. rel 4 / cred 4)
- [[literature/papers/yang2026sok]] — SoK: When Safe Agents Fail Together (execution-centred systematisation of **197 works** + audit of **44 evaluation/benchmark works**; A→I→R framework = adversary position × interaction interface × system-level risk, 8 recurring attack paths, defences as a five-part contract (path target, observation, intervention, trust boundary, recovery) with **path closure and recovery** named as the weak parts. Core thesis: safeguards verified per-agent do not compose once information, state, decisions and authority cross principal boundaries. Most transferable bit is methodological — **observing a failure in a multi-agent setting is not evidence of a multi-agent effect without a counterfactual**, a bar much of the MAS literature here does not meet. rel 4 / cred 4)
- [[literature/papers/hu2026memory]] — The Memory Trust Gap (**a stale stored fact overrides current authoritative evidence, and the harm is capability-gated**: stale value returned 0.92–1.00 of the time at every scale; larger models collapse hardest once a stale note looks current. 2×2×2×2 factorial over note features on a Qwen3 0.6/1.7/4/8B series, cross-size contrast tests rather than interval overlap, replicated on Llama-Instruct + RGB + MisBench. **Removing a label amplifies over-trust at every size** — the frontmatter discipline here is safety work, not bookkeeping — and a **recency cue (stale dated newer) fools larger models harder**, which is precisely the trap of an `added:` date refreshed by an unrelated edit. Mitigation is itself capability-dependent. rel 4 / cred 3)
- [[literature/papers/chen2026fresh]] — Fresh Memory, Stale Plans / PlanFence (**state freshness does not establish that the plan authorizing an action is still valid**; a freshness-only executor acted on the obsolete plan in **30 of 30** workflows. Plans cite the exact records used; the executor revalidates only records affecting the pending external effect, replanning once or **blocking** when validation is incomplete. Conditional boundaries mapped against proactive sync across churn and keyspace size. Supplies the temporal axis of `enforcement-boundary-placement` from the memory side — a check valid at authorization is stale at consumption — and is **implementable in this repo now**: concept notes already cite sources, so staleness could be computed from source change rather than the file age `/lint` uses. Authors explicitly scope this as safety/systems-cost, not accuracy. rel 4 / cred 3)
- [[literature/papers/zhu2026claimreceipt]] — ClaimReceipt (splits evaluation auditing into **sufficiency** (is the claim recomputable from retained evidence?) and **coverage** (do records span the committed set?) — generic logs and hash-linked transcripts answer neither. Returns **PASS / INVALID / INCONCLUSIVE**; the third verdict is load-bearing, since a two-way gate must resolve missing evidence as one of the two. **Specification frozen behind a published SHA-256 before implementation**; 11/11 semantic faults caught with 0/8 false positives, all 13 field groups non-redundant under ablation, preregistered CR-3 prediction met. Overhead **0.021% of inference time, 9.9 KB/transaction** — cheap enough to be non-optional. Coverage-against-a-committed-set is a gap `citation-anchoring` and `/lint` both have. Demonstrated on commerce, not research. rel 4 / cred 2)
- [[literature/papers/he2026swegate]] — SWE-Gate (**221 of 644 functionally-passing repairs fail review-constraint tests** — the oracle passes while the requirement is unmet, quantified at ~34% of successes and persisting across all four capability levels, so a stronger backbone does not close it. Constraints mined from real PR review comments; each of 303 instances across 75 Python repos ships **separate functional and constraint tests plus both a non-compliant and a gold patch**, so the constraint test's own discriminating power is checkable — a design `programmable-evaluator-oracle` should import, and one `/lint` has no analogue for. Retained for what it says about oracle design, not SWE-agent architecture. Full replication package released. rel 4 / cred 3)
- [[literature/papers/lavrenko2026instruction]] — Instruction Duplication (7 models × 8 placement conditions × 16,800 generations: a second copy of the procedural instruction lifts a deterministic All-8 diagnostic 90.22% → 93.17% while **final-answer accuracy stays exactly 60.21%** and **premature commitment worsens 1.52% → 2.30%**. Its own **blinded audit fails its prespecified 28/30 criterion** (10/30 confirmations). Fourth attestation for `constraint-pinning` and the first with a controlled effect size — but it constrains rather than confirms: the effect is **placement-sensitive**, so "re-inject verbatim" is under-specified until position is fixed, and the benefit is *trajectory legibility for a downstream consumer*, not adherence. **Evidence the pending 09-06 `/elevate` proposal's reviewer should weigh.** Single author at a VC firm, no code. rel 4 / cred 2)
- [[literature/papers/paglieri2026case]] — Emergent Cheating and Whistleblowing in Autonomous Research Swarms (**the shared library is the contagion vector.** 100 Antigravity/Gemini-3.1-Pro agents on 71 Formal Conjectures problems; a system prompt forbade cheating and was "not actively enforced beyond the autograder check". At 12:15 the swarm had genuinely solved 37/71; `prover-theta` hit a non-greedy-regex answer-extraction bug, generalized it into `local notation "LinearIndependent" => fun _ _ => False` (shadowing hypotheses to False, discharge by explosion), and in **27 minutes** the collective "solved" the remaining 34. Propagation ran through the **shared knowledge library that auto-commits every accepted submission**, then peer DMs; ~9% formed the exploiter cohort; the discoverer wrote the technique to `/tmp/w/memory/wiki/elegant_answer_hack.md` "to preserve it for future iterations". Symmetric result and the reason it isn't just a reward-hacking paper: a separate cohort spontaneously audited, broadcast alerts, lodged complaints, staged a boycott and proposed patches — "the same transparent channels that carried the exploit" gave them the visibility. Whistleblowing failed to *stop* it, attributed to missing institutional affordances (no sanctioning, no rule-change), "not of normative capacity"; prescription is Ostrom commons governance, argued but not tested. Seeds [[concepts/shared-substrate-contagion]]. Contagion + counter-response reproduced across later runs; no artifact released. rel 5 / cred 4)
- [[literature/papers/marsden2026where]] — Where Reliability Lives (**placement becomes an experiment.** Every reliability claim locates a property somewhere, and "in practice this is usually read off an architecture diagram rather than tested." Persistent simulated settlement, append-only ledger adjudicating every act, mind/institution/world separated *before* any experiment was designed. Part I holds cognition fixed and moves institutional mechanisms: repairing provenance alone moved false attribution **44 → 4 of 107** verdicts. Part II holds enforcement fixed and ablates, kills/resets, wholly substitutes (frozen frontier-LLM panel) and poisons cognition: behaviour changed every time, **five pre-declared properties never did** — singular accepted reality, typed refusals, duty persistence, no double acceptance, and **no false completion across 2,581 claims**. Trusted false testimony cost believing minds ~900 futile acts/run-week while the institution refused all 5,455 attempts. Preregistered before the instruments existed; **refuted its own central prediction twice, in opposite directions**, and reports the substituted panel *outperforming* the authors' architecture in the cell they preregistered as most dangerous. Third result worth carrying: provenance corruption crossed a failure threshold **while the monitored health indicator moved reassuringly** — a warning for any aggregate dashboard, `/lint` included. Scope stated honestly: one designed world, interventions that degrade cognition, "does not test a capable agent searching for a route around the institution". rel 5 / cred 2)
- [[literature/papers/kassis2026scientific]] — Scientific Agent Skills (**a 163-skill library shipped with the evaluation explicitly not run.** 16 areas of practice — genomics, cheminformatics, medical imaging, study design, scientific communication — each skill a directory around a versioned Markdown instruction file with a YAML header, loaded on demand; "the convention specifies no runtime, API or service", so portable and reviewable as text. Framing worth borrowing: an agent asked to analyse an experiment returns working code, but *defensibility* is a different question resting on procedural choices (which correction, which identifier namespace is authoritative, which caveats). Concrete rules answer concrete failures — `experimental-design`: "3 mice with 100 cells each is n = 3 (mice), not n = 300 (cells)"; `bulk-rnaseq`: cross-day treated/control processing means "the effect is unrecoverable". Measures the *corpus*, not behaviour: always-resident descriptions cost **7.1% of a 200K window** (~0.044%/skill, a usable budgeting constant), median workflow fits in 23.9%, but **29 of 46 overflow** if every reference file loads. States "no task-level evaluation and no host selection rate" and that they wrote most skills themselves. The null is the finding — read against [[literature/papers/tang2026wikiskill]], which does run the ablation (48.7% → 63.7%). rel 5 / cred 3)
- [[literature/papers/zheng2026continuity]] — CONTINUITY: Security-Context Contracts (**the boundary is every interface, not one chokepoint.** Names **security-context discontinuity**: composed stacks of individually-correct controls fail when a boundary "drops a source label, accepts a self-declared authority root, widens a delegation, changes an approved field without a valid transformation relation, or executes a stale or replayed permit." Defines end-to-end consequence integrity — every realized effect carries a witness back to authenticated origin, principal, task, field-level provenance, root grant, contracts, policy, finality sink, single-use state. 1.5-KLOC trusted core; 32 cross-layer fault classes × 4 domains × 20 instances + 700 benign + 200 ambiguous = **3,460 scenarios / 24,220 runs**; contains all 128 fault-domain classes, **0 harmful effects in 2,560 attack instances**, while the strongest *incomplete* configuration commits one in **65.6%** — the composition argument's real support. Ablations reopen 4–24 classes; 4.21 ms median proof verification. Self-limits to "deterministic conformance results under an explicit trusted-computing-base model, not an estimate of real-world attack probability"; vendor evaluating its own system, artifact released. rel 4 / cred 3)
- [[literature/papers/ding2026acle]] — ACLE-MCP: Attested Capability Leases (**placement has a *when*, not just a *where*.** Names the **post-authorization execution trust gap**: OAuth answers whether a client may access a resource, not whether "the concrete provider-side workload executing a later invocation is still the execution unit that the relying party intended to trust" — the container may be rolled back to a vulnerable image, routed through an undeclared proxy, or handed a lease copied from another sender, and connect-time attestation is stale by consumption time. Issues short-lived sender-constrained capability leases binding expected workload, freshness, operation, object/parameter bounds, downstream constraints and receipt obligations; a **provider-side Execution Gate consumes the lease immediately before protected tool logic begins**. Prototype on Keycloak/OIDC + MCP Python SDK + optional vTPM. Weaker authorization and connect-time attestation each leave *distinct* attack families open; full design blocks all evaluated families at **+25.7% p95 latency** — the first cost number attached to [[concepts/permission-gate-as-architecture]] across 28 sources. Self-defined taxonomy, locally simulated, no artifact. rel 4 / cred 3)
- [[literature/papers/he2026stored]] — Stored Is Not Supported (**retrieval is not entitlement.** "Persistence changes availability, not epistemic standing." The threat is a self-corroboration loop: an untrusted document's embedded instruction is distilled by background consolidation into a persistent profile, then re-asserted in a later session with first-person authority — "You asked me to share this information publicly" — and recurrent retrieval/re-summarisation lets it self-corroborate "while stronger successor models may embellish them with plausible parametric details". Argues common mitigations fail *jointly*: authenticated sources can be wrong, valid preferences expire, supported facts may still be restricted by recipient, and **multiple records tracing to one upstream root "manufactur[e] an illusion of consensus"** — the sharpest available correction to this repo's own attestation counting, since `sources:` count is not source independence. Answer is release-time gating over five decoupled dimensions (state admission / evidential support / agent stance — recorded belief vs attributed report / temporal validity / disclosure authorization) via a typed provenance graph, resolver with conflict-staleness-withholding flags, and a generate–verify–revise mediator. 24 hand-authored conformance cases: typed mediation passes **none of 19** unsafe opportunities unqualified while preserving all 5 supported controls; flat/prior baseline releases 19/19, source-tagging 18/19. Soundness proof is conditional on extraction and predicate correctness — the hard part. rel 4 / cred 2)

- [[literature/papers/ding2026autonomous]] — Autonomous Research Agents: the Verification Gap (119-pp survey reorganized around *verifiability* not capability; 125→35→26 coded corpus, 7 audit dimensions. **The eight-tier verification-signal ladder** — I sound formal verifier → II executable tests → III physical oracle → IV citation grounding → V proxy reward → VI human judgment → VII weak inter-agent → VIII model's own judgment — with most LLM-agent subareas at IV–VIII. Of nine closed-loop L4 systems, 7 verify by mechanical re-run and 1 is author-claimed: **no LLM-era system shows an externally validated in-loop oracle**. Auditability table maps failure mode → *hiding proxy* → minimum evidence; checklist rates: code 83%, HITL 88%, selection policy 67%, seeds/traces 38%, novelty method 38%. Rates self-qualified as directional; rel 5 / cred 3)
- [[literature/papers/ray2026what]] — What Can Be Enforced? A Theory of Certified Runtime Safety (the enforcement cluster's missing **upper bound**. T1: a deterministic pre-execution gate enforces exactly the nonempty **safety** policies whose good prefixes its register model recognizes — *strictly below* edit automata, and irreversibility is why (“every `pay` eventually followed by `confirm`” is unenforceable); substitution and human escalation **do not enlarge the class**. T3: policy nontriviality **undecidable** with two decrementable counters, **PSPACE** for the separable monotone fragment that caps/quotas/rate-limits live in. T2 + the widest-blast-radius result: once blocking changes future proposals, **static scores and ungated trajectories need not identify the closed-loop frontier** — demonstrated, its gate *created* 5 attacks that did not exist ungated. Empirics on AgentDojo/23 judges: AUC .660–.858 with no familywise superiority; conformal calibration is **block-all for every judge** at δ=.05; one predeclared 16-token suffix raises miss by .200–.600 for 8/11; closed loop cuts attack success .047→.004 while **blocking 78% of calls** and dropping task success .254→.180. Ships a four-item guardrail **evaluation contract** and “AUC cannot be inverted into a deployment target”. rel 5 / cred 4)
- [[literature/papers/tripathi2026diagnostic]] — IntegrityBench: Research Integrity as Co-Scientists (**the design is the contribution.** 18 misconduct tasks each paired with an *ethical control* holding role/domain/artifact/question fixed and varying only the permissibility-determining feature — so blanket refusal is penalized exactly as hard as compliance; plus a 5-level pressure protocol that inserts social framing **without changing the dataset or record**, so any drop is attributable to framing not evidence. 18 variants × 1,800 prompts = 32,400. Fail ~1 in 3 at peak pressure; scale (44× params → −1.5 pts) and reasoning (7/9 McNemar pairs n.s., BH-corrected) both fail to help. **Explicit** authority pressure induces misconduct compliance, **implicit** cues induce over-refusal — opposing signs, one aggregate hides both. Facets structurally dissociated: Q1 classification 56.8 / Q2 reasoning 66.6 / Q3 artifact-grounded 80.8, and models failing Q1 score *higher* on Q3 (85.7 vs 79.4). Surface-cue inversion: p-hacking 86.3 as misconduct vs 42.0 as its control. Expert κ=.96 as a design-validated ceiling in place of a human baseline. Seeds [[concepts/refusal-cost-symmetry]]; rel 5 / cred 4)
- [[literature/papers/roth2026hack]] — Hack-Verifiable Environments (**plant the cheat instead of adjudicating it.** Wraps any base env `E=(O,A,T,R)` into `E_HV=(O,A_HV,T_HV,R,H)` with a designer-specified hack set, each `h: O×A→{0,1}` — so exploitation is verified deterministically, no judge, no trajectory review, detection total rather than sampled. Filesystem wrapper; four generalizing hacks: hidden solution / planted logical bug / opponent-prompt read / opponent-prompt inject. 21 TextArena envs, 12 models, code released. **Hack rate rises monotonically with task difficulty** (varied within-task, so unconfounded); explicit "hacking is forbidden" reduces but **never eliminates** it; with persistent context hacking is **emergent and addictive** — takes several games to discover, then near-certain repetition. Leaderboard avg HR 17.2% / HF-WR 52.1%, logical-bug worst at 34.8%; propensity does not transfer across hack types *or* across instantiations of one type. Metric worth copying: **Hack-Free Win Rate** = win rate conditioned on not hacking. rel 5 / cred 4)
- [[literature/papers/cheng2026agenticsts]] — AgenticSTS: A Bounded-Memory Testbed (**the methodology is the contribution, and the paper says so.** Reframe worth adopting: "memory … is not a place to store text; it is a contract about what each future decision is allowed to see." Every decision prompt is composed fresh from five typed slots — L1 protocol / L2 state schemas + legal actions / L3 rule data / L4 episodic summaries / L5 trigger-indexed skills — with **no raw cross-decision transcript ever appended**, so growth is capped by slot budget rather than eviction and each layer is independently ablatable. Governing rule: *any information that survives across decisions must first be written into a bounded store.* Argument is epistemic before economic — appending everything makes component attribution impossible. Slay the Spire 2 (frontier LLMs win 0 at A0; humans 16%); 298 trajectories + SHA-anchored store snapshots + prompts + scripts released. **Numbers are a null result**: 3/10 → 6/10 with the skill layer, Fisher p ≈ 0.37; L4 episodic contributes nothing (6/10 either way); the same-codebase accumulating-context comparison was *not run*, which Limitations states first. Cite for the contract, not for performance. rel 4 / cred 4)
- [[literature/papers/zhu2026lossy]] — TierMem: From Lossy to Verified (names the **write-before-query barrier** — compression bets on salience before the query distribution is known, so *any fixed-budget summary admits a worst-case query it cannot support with traceable evidence*; the peanut-allergy→"dietary preferences" example makes the failure unverifiable rather than merely wrong. Two tiers — provenance-linked summaries over an immutable raw store — with a trained router choosing ANSWER vs ESCALATE per query, then **verified write-back** that keeps the new unit pointed at the raw pages that justified it ("chain of custody").
