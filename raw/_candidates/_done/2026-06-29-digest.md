## Skill-library lifecycle & procedural memory

1. **Managing Procedural Memory in LLM Agents: Control, Adaptation, and Evaluation** — method + benchmark
   - https://arxiv.org/abs/2606.23127 · arXiv v1 Jun 22 2026
   - Belikova, Parchiev, Egorov, Davydenko, Gusev, Savchenko, Makarenko.
   - Introduces **AFTER**, a benchmark of 382 enterprise tasks across six
     professional roles for measuring how procedural-memory skills *transfer*
     between agents/roles. Headline empirical result: procedural memory gives
     consistent gains in production workflows, but transferability is uneven —
     some skills generalize broadly while others specialize to a role and
     **lose effectiveness when transferred**. This is a direct, measured
     attestation of the write-policy / consolidation tension at the heart of
     `skill-library-lifecycle` (when is a skill worth keeping / sharing vs.
     pruning) and connects to `multi-granularity-memory` (role-specialized
     vs. general stores). No code URL surfaced yet.
   - reason: cleanest in-window hit; supplies an evaluation harness +
     transfer-degradation finding that sharpens `skill-library-lifecycle`'s
     "skills can become specialized and stale" claim. Candidate anchor for a
     procedural-memory-evaluation note.

## Auditable autonomous research & governance gating

2. **Agentic AutoResearch for Space Autonomy: An Auditable, LLM-Driven Research Agent for Aerospace Control Problems** — system
   - https://arxiv.org/abs/2606.20394 · arXiv v1 Jun 18 2026
   - AutoResearch: an LLM autonomously optimizes aerospace control policies by
     iteratively editing training scripts and logging outcomes. Trustworthiness
     comes from a **credibility layer built into the loop** that certifies each
     reported result via three audits: (a) per-problem seed-noise measurement,
     (b) reseeded verification of top configurations, (c) leave-one-out pruning
     of the agent's own modifications — so no result is credited unless it
     survives the checks.
   - reason: a 4th-domain (aerospace control) attestation that hits two active
     fronts at once. The seed-noise + reseeded-verification audits are a
     concrete instance of `pass-at-k` / variance-aware scoring and of
     `citation-anchoring`/`programmable-evaluator-oracle` grounding; the
     in-loop credibility gate is a `permission-gate-as-architecture` analogue
     applied to *result acceptance* rather than tool calls. Slipped the prior
     digest (Jun 18, before its 06-22 run but above its 2606.13681 high-water);
     novel to the graph. Slightly out of the strict window — included on
     cross-front value, flagged for curation judgment.
