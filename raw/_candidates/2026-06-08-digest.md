## Autonomous ML-research agents (dominant focus)

1. **MLEvolve: A Self-Evolving Framework for Automated ML Algorithm Discovery** — method
   - https://arxiv.org/abs/2606.06473 · arXiv Jun 4 2026
   - Extends tree search to "Progressive MCGS" (cross-branch reference edges,
     entropy-scheduled explore→exploit) and adds "Retrospective Memory"
     (cold-start KB + dynamic global memory). SOTA on MLE-Bench at a 12h
     budget (half standard runtime); beats specialized discovery methods on
     math optimization.
   - reason: hits three live concepts at once — `evolutionary-expansion` /
     `evolutionary-search-grain` (MCGS, search grain), `agent-native-memory`
     (retrospective/global memory in the loop), and the dominant ML-research-
     agent / MLE-bench front. Top-priority ingest.

2. **AutoMedBench: Towards Medical AutoResearch with Agentic AI Models** — benchmark
   - https://arxiv.org/abs/2606.01961 · arXiv Jun 2026
   - Workflow-aware benchmark for autonomous medical-AI research; organizes
     agent execution into a five-stage research workflow with stage-level
     scoring.
   - reason: in-scope as general scientific-research automation where the
     architecture transfers (cf. Kosmos); the five-stage decomposition is an
     evaluation/grounding angle for `hce-evaluation` + `typed-claim-partition`.

## Agent memory & multi-granularity retrieval

3. **Agent Memory: Characterization and System Implications of Stateful Long-Horizon Workloads** — systems analysis
   - https://arxiv.org/abs/2606.06448 · arXiv Jun 4 2026
   - First systems characterization of agent memory: a four-axis taxonomy
     (flat retrieval → LLM-mediated extraction → consolidating fact stores →
     agentic control flows) and a phase-aware profiling harness attributing
     cost to construction, retrieval, and generation across ten systems / two
     benchmark suites.
   - reason: a systems-cost yardstick for the memory cluster — directly
     informs `agent-native-memory`, `selective-memory-retrieval`,
     `context-eviction-policy`, and the `multi-granularity-memory` seed NOTES
     flagged for crystallization. Strong MoC-supporting attestation.

4. **Human-Inspired Memory Architecture for LLM Agents** — method
   - https://arxiv.org/abs/2605.08538 · arXiv May 2026
   - Cognitively-motivated multi-store memory (working / episodic / semantic)
     with consolidation between tiers.
   - reason: a fourth independent attestation for `multi-granularity-memory`;
     helps tip the memory cluster toward MoC-ripeness (NOTES "Next" asked to
     re-check this).

## Permission-gate-as-architecture (crystallizing seed)

5. **FinHarness: An Inline Lifecycle Safety Harness for Finance LLM Agents** — method
   - https://arxiv.org/abs/2605.27333 · arXiv May 2026
   - Query Monitor (single-turn intent fused with cross-turn drift into a
     session risk cumulant) + Tool Monitor (per-call permission/parameter/
     sequence priors) + a sliding-window risk Cascade. Frames the harness as
     a *regulator over the agent's policy*, not merely a gate in front of it.
   - reason: a concrete fourth-domain attestation for the
     `permission-gate-as-architecture` seed NOTES flagged as ready to
     crystallize; the "regulator vs gate" framing is a sharper claim than the
     prior liu2026dive / wang2026reframing sources.
